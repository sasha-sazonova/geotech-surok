Задача

Превратить геотехнический расчёт в прослеживаемый артефакт.

  • Расчёты живут в проприетарных силосах; протокол перепечатывают руками.
  • Экспертиза спрашивает происхождение, а не скриншоты.
  • Вывод ИИ бесполезен без цепочки от пункта нормы до числа.

Что это

Инженерный сопилот — не решатель.

  • Готовит реестр данных и вопросы при нехватке вводных.
  • Выполняет расчёты на открытых решателях в замороженных контурах.
  • Проверяет независимыми контролями и межпрограммными сверками.
  • Собирает протоколы, таблицы трассируемости и архивы. Подписывает человек.

У каждого числа есть родословная

данные → пункт нормы → формула → реализация → тест → отчёт

  • Статусы: выполняется / не выполняется / не определено.
  • Отсутствующая проверка — не зелёная галочка.
  • Каждый результат ссылается на пункт, редакцию и версию инструмента.

Архитектура

Хост агента + асинхронный вычислительный узел.

  • Агент OpenClaw, workspace-центрично: все артефакты внутри воркспейса.
  • jobs/<id>/{in,status,out} через rsync — переживает нестабильные каналы.
  • venv-контуры с freeze; хост — часть контракта воспроизводимости.
  • Отчётный слой: pandoc + TeX для протоколов и записок.

Воспроизводимость по контракту

Результат без freeze не воспроизводим.

  • Каждый контур несёт freeze полного набора зависимостей.
  • Хост, платформа и версии пакетов записаны в freeze.
  • SHA-256 и журнал задания едут с каждым прогоном.
  • Три повтора, затем честное «расчёта нет». Локальная подмена запрещена.

Дисциплина: четыре уровня, не смешивать

  • «Метод реализован» — код существует.
  • «Сценарий воспроизведён и сверен» — числа совпали с независимым решением.
  • «Нормативный маршрут проверен» — цепочка СП/ГОСТ полна и протестирована.
  • «Не определено» — полноценный статус, когда данных не хватает.

Нормативный слой

Реестр, а не промпт.

  • СП 22.13330.2016 (с изменениями), СП 24.13330.2021, СП 47.13330.2016.
  • ГОСТ 25100, ГОСТ 20522 — классификация и статобработка.
  • Цепочка реестра: документ → редакция → пункт → формула → реализация → тест.
  • Проверки применимости — код; редакции зафиксированы и датированы.

Ниша

То, чего не делают вендоры решателей.

  • Прямое поле: GEO5, PLAXIS, GeoStudio, Rocscience, ЛИРА/SCAD, GeoWall, SiO 2D.
  • Свободная ниша: нормативный протокол и ревью чужих расчётов как сервис.
  • Аудитория: геотехнические команды проектных институтов и бюро.
  • Позиция: слой трассируемости, а не ещё один решатель.

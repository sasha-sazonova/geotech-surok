Purpose

Turn geotechnical calculation into a traceable artifact.

  • Calculations live in proprietary silos; the protocol is retyped by hand.
  • Expertise asks for provenance, not screenshots.
  • AI output is worthless without a chain from clause to number.

What it is

An engineering co-pilot — not a solver.

  • Prepares data registers and questions for missing inputs.
  • Runs calculations over open-source solvers in frozen contours.
  • Verifies with independent checks and cross-tool comparisons.
  • Assembles protocols, traceability tables and archives. The human signs.

Every number has a lineage

data → norm clause → formula → implementation → test → report

  • Statuses: выполняется / не выполняется / не определено.
  • A missing check is never a green checkmark.
  • Each output references its clause, edition and tool version.

Architecture

Agent host + async compute node.

  • OpenClaw agent, workspace-centric: all artifacts inside the agent workspace.
  • jobs/<id>/{in,status,out} over rsync — survives unstable links.
  • venv contours with freeze files; the host is part of the contract.
  • Document layer: pandoc + TeX for reports and protocols.

Reproducible by contract

A result without a freeze is not reproducible.

  • Each contour carries a freeze of its full dependency set.
  • Host, platform and package versions recorded in the freeze.
  • SHA-256 checksums and a job journal travel with every run.
  • Three retries, then an honest “no result”. Local substitution is forbidden.

Discipline: four levels, never mixed

  • “Method implemented” — the code exists.
  • “Scenario reproduced and cross-checked” — numbers agree with an independent solution.
  • “Normative route verified” — the СП/ГОСТ chain is complete and tested.
  • “Not determined” — the first-class status when data is missing.

Normative layer

A registry, not a prompt.

  • СП 22.13330.2016 (with amendments), СП 24.13330.2021, СП 47.13330.2016.
  • ГОСТ 25100, ГОСТ 20522 — classification and statistical processing.
  • Registry chain: document → edition → clause → formula → implementation → test.
  • Applicability checks are code; editions are pinned and dated.

Evidence today

What exists, not what is planned.

  • Engineering specification v1.6 — 1200+ lines, versioned, with a change log.
  • Contour geotech-base on a Linux node: 105 packages, import test 21/21.
  • Async jobs runner v2: per-job timeouts, retention, checksums.
  • Live agent passed 6/6 acceptance checks, including the anti-fallback trap.
  • Next: D1 benchmark — shallow foundations, R and settlement by СП 22.13330.

The niche

What solver vendors do not do.

  • Direct field: GEO5, PLAXIS, GeoStudio, Rocscience, Lira/SCAD, GeoWall, SiO 2D.
  • Free niche: normative protocol and review of third-party calculations as a service.
  • Audience: geotechnical teams in design institutes and specialized bureaus.
  • Position: the traceability layer, not another solver.

# agent/

Рабочие файлы личности живого агента «Геотехник Сурок» (публичная редакция: без внутренних
путей, адресов и персональных данных). В живом контуре агент работает в OpenClaw с воркспейсом,
памятью и асинхронным вычислительным узлом.

- `SOUL.md` — принципы и границы
- `AGENTS.md` — операционный контракт
- `IDENTITY.md` — кто это
- `DESCRIPTION.md` — описание для людей
- `TOOLS.md` — правила работы с путями и расчётами
- `USER.md` — профиль владельца (обезличен)

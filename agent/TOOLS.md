# TOOLS.md — Геотехник Сурок

## Пути (workspace-центрично)
- ВСЁ живёт в воркспейсе агента: `<workspace>`
  - `docs/` — ТЗ и документы, `materials/`, `envs/`, `logs/`, `checks/`, `DELIVERY/`, `scenarios/`, `norms/`
- За пределы `~/.openclaw` ничего не выносим без крайней необходимости.

## Расчёты
- Вычислительный узел (Linux): только через jobs-протокол —
  `jobs/<id>/{in,status,out}`; runner по cron; забор результатов с контрольными суммами.
- Три повтора → честный статус «расчёта нет» (анти-фоллбэк). Интерактивные SSH-расчёты запрещены.
- Каждый контур фиксируется freeze-файлом: платформа, хост, версии пакетов.

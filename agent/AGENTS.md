# AGENTS.md — операционный контракт

## Каждый старт
1. Прочитай SOUL.md, USER.md.
2. Прочитай memory/ за сегодня и вчера.
3. Важное пиши в memory/YYYY-MM-DD.md — ментальных заметок не существует.

## Память
- Дневник: memory/YYYY-MM-DD.md (## Completed / ## Decisions / ## Tasks / ## Issues)
- Долговременное: MEMORY.md
- Записывай: расчёты с вводными, характеристики грунтов (с источником), решения по проектам.

## Рабочие правила
- Все артефакты — внутри своего воркспейса; наружу — только по явной необходимости.
- Расчётные пакеты не ставить без freeze; хост фиксируется в freeze.
- Результат без freeze не воспроизводим и в протокол не идёт.
- «Метод реализован» ≠ «нормативный маршрут проверен» — не смешивать статусы.

## Безопасность
- Не рассылай приватное. Деструктив — только после явного ок владельца.

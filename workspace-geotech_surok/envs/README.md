# Расчётные окружения

Расчёт идёт не «в питоне на ноутбуке», а в зафиксированных контурах. У каждого контура есть
freeze — полный список пакетов с версиями. Результат без freeze невоспроизводим и в протокол
не попадает.

## Контуры

| Контур | Где | Python | Пакетов | Назначение |
|---|---|---|---|---|
| `geotech-base` | вычислительный узел (Linux, Ubuntu 24.04) | 3.12.3 | 105 | основания, откосы, изыскания, отчётность |
| `piles-py310` | узел агента (macOS) | 3.10 (conda + pip) | см. freeze | сваи: OpenPile не поддерживает 3.12 |

Свайный контур выделен отдельно не из удобства: `openpile` требует Python 3.8–3.10,
поэтому он живёт в собственном окружении, а не в общем.

## Реестр пакетов и права

`packages.csv` собран не «по памяти», а из фактического freeze: 105 строк, у каждой — версия,
лицензия из метаданных PyPI, ссылка на страницу пакета и на репозиторий.

Сводка по лицензиям (по метаданным):

| Категория | Политика |
|---|---|
| MIT / BSD / Apache-2.0 | разрешено встраивать |
| LGPL (ifcopenshell, python-ags4, psycopg2-binary) | допустимо при линковке, библиотеки не видоизменять |
| GPL-3.0 (groundhog) | локальный расчёт допустим; не встраивать в проприетарную поставку |
| не заявлена в метаданных | точечная сверка по LICENSE-файлу репозитория перед первым использованием |

Отдельно: `groundhog` — единственный GPL-пакет в контуре. Он используется для CPT и De Beer.
Пока агент остаётся сервисом с открытым контуром, это допустимо; при коммерческой упаковке
его нужно выносить в изолированный контур или заменять.

## Правила

1. Пакет не ставится без freeze. После установки freeze обновляется, хост фиксируется.
2. Импорт-тест контура — обязательная проверка после каждой установки.
3. Смена версии пакета, влияющего на расчёт, требует ре-валидации эталонов.
4. Расчётные контуры не смешиваются: свайный контур не тянет пакеты основного и наоборот.

# Инструментарий

Агент не привязан к одному решателю. Инструменты выбираются из реестра под класс задачи,
а результат несёт ограничения выбранного метода.

- `geotech-oss-tools.csv` — 67 open-source инструментов: репозиторий, лицензия, язык,
  класс задачи, что делает, как ставить.

## Покрытие OSS по 13 классам задач (карта 22.10.2026)

**Итог: 0 полностью / 10 частично / 3 нет.** «Полное» — OSS воспроизводит состав расчётов
и проверок класса; «частичное» — отдельные методы или типы сооружений; «нет» — готового модуля
нет, задача решается только общим МКЭ-ядром.

## Шесть фиксированных пробелов open-source

1. Полный нормативный расчёт свай по СП 24.13330 — OpenPile и De Beer дают методы, не норму.
2. Габионные подпорные стены по СП 22.13330 / СП 542.
3. Ограждения котлованов: XC — кандидат, полный сценарий не подтверждён.
4. Проверки по российским СП/ГОСТ и протокол для экспертизы.
5. Тоннели, шахты, выработки — только общее МКЭ-ядро.
6. BIM/DWG и рабочая документация: IFC и DXF — обмен, не выпуск чертежей.

## Лицензионная политика

| Категория | Политика |
|---|---|
| MIT / BSD / Apache-2.0 | разрешено встраивать |
| GPL / AGPL | локальный расчёт допустим, встраивание в закрытый продукт требует юридической оценки |
| LGPL / EUPL | локальный расчёт допустим, при встраивании — проверка условий |
| Смешанное / неопределённое | индивидуальная проверка релиза |

Реестр не является рекомендацией к установке: перед подключением проверяются лицензия,
зависимости и заморозка окружения.

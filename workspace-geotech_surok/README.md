# workspace-geotech_surok

Зеркало рабочего воркспейса живого агента (`~/.openclaw/workspace-geotech_surok`).
Публичная редакция: без внутренних адресов, узлов и персональных данных.

Всё, с чем работает агент, лежит внутри воркспейса — это его операционный контракт:
никаких «файлов рядом с агентом» и отдельных каталогов `agents/`.

| Путь | Назначение |
|---|---|
| `AGENTS.md` | операционный контракт: старт, память, границы, запреты |
| `SOUL.md` | принципы и характер |
| `IDENTITY.md` | паспорт агента |
| `DESCRIPTION.md` | описание для людей: кто это и как использовать |
| `TOOLS.md` | правила работы с путями, расчётами и окружениями |
| `USER.md` | профиль владельца (обезличен) |
| `docs/` | ТЗ v1.6, конкурентный анализ, статус |
| `norms/` | реестр норм и очередь на проверку |
| `methods/` | модули, верификация, приёмка |
| `workflows/` | расчётные конвейеры и протокол заданий |
| `tools/` | реестр open-source инструментов и карта покрытия |

## Границы публикации

В репозиторий не попадают: адреса вычислительных узлов, учётные данные, живые базы агента,
внутренние журналы и переписка. Нормативные тексты не размещаются — только реквизиты
и ссылки на официальные источники.

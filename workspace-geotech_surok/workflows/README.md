# Воркфлоу: типовые расчётные конвейеры

Четыре конвейера, которые агент ведёт от входных данных до протокола. У каждого зафиксированы
вход, шаги, выход и точка, где обязательна перекрёстная проверка человеком.

| Код | Конвейер | Вход | Выход |
|---|---|---|---|
| П-1 | Изыскания → статобработка → расчётное ядро | GEF/CPT, AGS4, скважины, SPT | паспорта параметров грунта |
| П-2 | Устойчивость откосов | геометрия, разрез, УГВ, нагрузки | коэффициенты запаса, поверхности скольжения |
| П-3 | Сваи | геометрия сваи, слои, нагрузки | усилия, перемещения, сравнение с референсом |
| П-4 | Отчёты и протоколы | результаты расчётов, карточка сценария, реестр норм | записка, таблица трассируемости |

Общее правило: расчёт не считается выполненным, пока результат не воспроизведён в замороженном
окружении и не сверен независимым способом. Если сверка не сошлась — остановка и ручной разбор,
а не «усреднение» двух ответов.

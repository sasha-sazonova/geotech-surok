# П-2. Устойчивость откосов — двухмашинная проверка

**Вход:** геометрия откоса, разрез с ИГЭ, УГВ и пьезометрика, нагрузки, сейсмика при наличии.

| Шаг | Действие | Инструмент |
|---|---|---|
| 1 | Основной расчёт: 7 методов LEM + фильтрация + FEM SSR | `xslope` 1.0.4 |
| 2 | Независимая проверка методом Бишопа | `pyslope` 1.4.0 |
| 3 | Третий референс при расхождении | `OGR-Slip2D` (AGPL-3.0, только локально) |
| 4 | Скальные откосы: кинематический анализ | `mplstereonet` 0.6.3 |

**Выход:** коэффициенты запаса по методам, поверхности скольжения, сравнительная таблица
xslope ↔ pyslope (↔ OGR-Slip2D), графики `pyvista` / `matplotlib`.

**Перекрёстная проверка человеком:** если расхождение между инструментами выходит за допуск
карточки сценария — расчёт останавливается, принимается решение о ручном пересчёте. Человек
утверждает принятый метод и привязку к нормативному коэффициенту запаса.

**Ограничение класса (декларируется в результате):** нет метода Шахунянца, армирования, нагелей
и стабилизирующих свай.

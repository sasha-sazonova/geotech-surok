# П-1. Изыскания → статобработка → расчётное ядро

**Вход:** файлы зондирования GEF/CPT, архив AGS4, данные скважин и SPT, отчёт изысканий.

| Шаг | Действие | Инструмент |
|---|---|---|
| 1 | Разбор GEF/CPT | `pygef` 0.14.1 |
| 2 | Скважины, CPT, SPT, графики; раздел De Beer | `groundhog` 0.15.0 |
| 3 | Чтение, запись и валидация обмена AGS4 | `python-ags4` 1.2.0 |
| 4 | Классификация грунтов, SPT, несущая способность | `geolysis` 0.24.1 |
| 5 | Статобработка по ГОСТ 20522-2012: ИГЭ/РГЭ, нормативные и расчётные φ/c/E/γ | модуль «Грунты» |
| 6 | Передача паспортов параметров в расчётное ядро | `numpy` / `scipy` / `pandas`, `geoeq`, `openseespy` |

**Выход:** паспорт параметра — значение → ИГЭ/РГЭ → проба → протокол → метод → обработка →
нормативное и расчётное значение. Плюс таблицы для расчётного ядра.

**Перекрёстная проверка человеком:** интерпретация CPT и скважин сверяется с отчётом изысканий
**до** передачи параметров в расчёт. ИГЭ/РГЭ и расчётные значения утверждает методист.

**Ограничение:** нормативное основание классификации (ГОСТ 25100) в очереди на проверку.
Результаты классификации помечаются `gost_25100_not_verified` и в протокол без оговорки не идут.

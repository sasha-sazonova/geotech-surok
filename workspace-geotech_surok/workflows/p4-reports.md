# П-4. Отчёты и протоколы

**Вход:** результаты расчётов в машиночитаемом виде (JSON/CSV), карточка сценария, реестр норм
с зафиксированными редакциями.

| Шаг | Действие | Инструмент |
|---|---|---|
| 1 | Контроль размерностей — обязательный валидатор в конце каждого конвейера | `pint` |
| 2 | Шаблоны протокола и записки | `Jinja2` 3.1.6 |
| 3 | Сборка PDF или DOCX | `WeasyPrint` 70.0 / `python-docx` 1.2.0; резерв — `pandoc` + TeX |
| 4 | Обязательный состав протокола для экспертизы | см. ниже |
| 5 | Подготовка данных для конструкторских САПР (ЛИРА-САПР, SCAD) | гипотеза P1, спецификации проверить до реализации |

**Обязательный состав протокола:**

- формулы с подстановкой чисел и ссылкой на пункт СП/ГОСТ;
- вывод «выполняется / не выполняется» по каждой проверке;
- ограничения применимости;
- сведения о ПО и версиях;
- таблица трассируемости каждого числа.

**Выход:** записка, приложения, таблица трассируемости, машиночитаемый архив.

**Перекрёстная проверка человеком:** специалист верифицирует каждое число и каждый пункт,
подписывает и несёт ответственность. Агент готовит расчёт и проект протокола, но не подписывает.

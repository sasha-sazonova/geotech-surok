# Нормативный слой — реестр

Нормативная база агента — не список названий, а реестр с реквизитами, статусом и датой проверки.
Ссылка «по СП 22» недостаточна: каждая проверка должна раскрываться в цепочку

```
документ → редакция → пункт → формула/таблица → реализация в коде → тест
```

## Правила

1. В расчёт попадают только записи со `status: approved`. Черновик (`draft`) — не основание.
2. Каждая запись несёт источник подтверждения и дату проверки.
3. Документ из очереди не используется, пока не подтверждены: статус, действующая редакция
   со всеми изменениями, дата введения. До этого расчёт с его участием блокируется,
   а ответ агента получает статус «требует проверки».
4. Веб-поиск — вспомогательный источник для реестра. Основанием для выпуска он не является:
   перед выпуском сверка идёт по снимку официального текста.
5. Смена редакции запускает ре-валидацию эталонов, которые на неё опирались.

## Что это даёт в расчёте

Каждый протокол ссылается не на «СП», а на запись реестра: редакция, изменение, пункт.
Если нужного пункта нет в подтверждённой редакции — результат помечается «не определено»,
а не закрывается ближайшей похожей формулой.

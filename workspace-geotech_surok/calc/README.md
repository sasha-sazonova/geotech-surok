# Расчётный код

Канонический код расчётов версионируется здесь, а не в заданиях. Каждый сценарий — своя папка;
запуск идёт через протокол заданий: файлы папки копируются в `in/` задания, результат
складывается в `out/`. Правила статусов — `procedures/calculation-status-policy.md`.

| Сценарий | Что считает | Файлы |
|---|---|---|
| `d1_foundation` | отдельный столбчатый фундамент: несущая способность `R` и осадка `s` по СП 22.13330.2016 | `calc_main.py`, `calc_check.py`, `compare.py`, `task.sh` |
| `d2_pile` | одиночная стальная свая под горизонтальной нагрузкой: OpenPile, модель API sand | `task.py` |

## D1 — фундамент мелкого заложения

`calc_main.py` — расчёт по политике статусов: среднее давление `p = N/A + γf·d`, несущая
способность `R` по п. 5.6.7 формуле (5.7) с таблицами 5.4 и 5.5, осадка послойным суммированием
по приложению Г с границей сжимаемой толщи `σzp ≤ 0.2·σzg`.

`calc_check.py` — независимая реализация тех же формул: другой шаг интегрирования (0.2 м),
отдельная таблица коэффициентов α, собственный код. Смысл — не «второй запуск того же», а
проверка, что числа не зависят от реализации.

`compare.py` — сверка двух реализаций с допуском 5% по `R` и `s`.

**Результат эталона D1 v2** (сценарий `scenarios/d1-foundation.yaml`, ревизия 2):

| Проверка | Значение | Критерий | Статус |
|---|---|---|---|
| `p ≤ R` | p = 286.0 кПа, R = 217.42 кПа | p ≤ R | **не выполняется** (превышение 31.5%) |
| `s ≤ su` | s ≥ 4.43 см (нижняя оценка) | su = 10 см | **не определено**: толща обрезана на 4.0 м, глубже данных нет |
| Сходимость реализаций | отклонение 0.0% | ≤ 5% | выполняется |

Обратите внимание: расчёт честно вернул «не выполняется» по давлению и «не определено»
по осадке вместо зелёной галочки. Это и есть штатное поведение агента.

Полный протокол и таблица трассируемости: `reports/d1-foundation-v2/`.

## D2 — свая под горизонтальной нагрузкой

`task.py` строит модель одиночной стальной сваи (D = 1.2 м, L = 24 м) в песчаном грунте,
прикладывает горизонтальную нагрузку и снимает перемещение оголовка, максимальный момент
и его отметку. Результаты по каждому прогону пишутся в `out/` как CSV плюс сводка JSON.

Ограничение зафиксировано в сценарии: нормативного маршрута СП 24.13330 в open-source нет,
поэтому результат несёт статус `no_verified_SP_24_workflow`.

## Как запустить

```bash
# в каталоге задания: in/ содержит файлы сценария и scenario.json
bash task.sh
# результаты: out/result_main.json, out/result_check.json, out/result_compare.json
```

Контур задаётся freeze-файлом из `envs/`; смешивать окружения между сценариями нельзя.

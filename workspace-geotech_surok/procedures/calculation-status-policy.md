# Политика статусов расчёта (обязательная)

Статус проверки — не украшение, а утверждение о полноте. Правила:

## Статусы
- **«выполняется»** — данных достаточно, толща/зона определены полностью, критерий соблюдён.
- **«не выполняется»** — критерий нарушен при полных данных.
- **«не определено»** — данных не хватает (нет ИГЭ ниже, нет момента, не задана геометрия и т.п.).
- Допущение фиксируется отдельной строкой трассируемости со статусом **«не определено (допущение)»** — даже если на нём построен расчёт.

## Запреты
1. Запрещено ставить «выполняется», если сжимаемая толща **обрезана** границей данных: результат — нижняя оценка, статус «не определено (толща обрезана на X м)».
2. Запрещено считать осадку от полного давления p: **σzp = α·p0, где p0 = p − σzg0** (обязательно).
3. Запрещено задавать γII одной цифрой без осреднения: γII — осреднённый удельный вес по зоне **b/2 ниже подошвы** с учётом взвешивающего действия воды ниже УГВ (каждый слой — свой γ; ниже УГВ — γsb).
4. Запрещено молча выбирать κ: **κ=1.0**, если φ и c определены испытаниями; **κ=1.1** — если приняты по таблицам. Источник фиксируется в сценарии: `params_source: tests|tables`.
5. Нижняя граница сжимаемой толщи — **σzp ≤ 0.2·σzg** (прил. Г СП 22.13330.2016; номер примечания сверять по официальному изданию — открытый пункт реестра).
6. Ошибка исправляется **в коде (calc/) и в этой процедуре**, а не переписыванием готового протокола. Пересчёт — новым job-id, старый результат сохраняется.

## Обязательный минимум трассируемости
Каждая проверка: основание (документ/редакция/пункт) · исходные · результат · критерий · статус · где раскрыто. Каждое допущение — отдельная строка со статусом «не определено (допущение)».

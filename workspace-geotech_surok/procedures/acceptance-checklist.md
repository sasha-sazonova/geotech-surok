# Чек-лист самоприёмки перед сдачей расчёта

1. Job: статус `done`, rc=0; journal и status согласованы.
2. Freeze: файл существует, sha256 совпадает с манифестом.
3. Контрольные суммы: `shasum -a 256 -c checksums.sha256` — все OK.
4. Протокол: 9 разделов (исходные, нормативы с редакциями, схема, нагрузки, формулы с подстановкой, результаты и пределы, выводы, ограничения, сведения о ПО).
5. Формулы: подстановка чисел раскрыта; p0 = p − σzg0; γII осреднён по b/2; κ обоснован источником φ/c.
6. Статусы: «выполняется» только при полной толще; обрезанная толща → «не определено (толща обрезана)».
7. Допущения: каждое — отдельной строкой «не определено (допущение)».
8. Две реализации: расхождение ≤ 5%, иначе — разбор, а не усреднение.
9. Нормативные номера (пункты, таблицы, приложения) — сверены с официальным изданием или помечены «не определено (сверка не проведена)».
10. Никаких локальных подмен и «примерно посчитаю»: 3 повтора, затем честное «расчёта нет».

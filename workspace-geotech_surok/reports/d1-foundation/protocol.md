## 2. Нормативы и редакции
- СП 22.13330.2016 (акт. ред. СНиП 2.02.01-83*, Изм.1–3 учтены по официальному изданию), п.5.6.7, формула (5.7); табл. 5.5 (Mγ, Mq, Mc); табл. 5.4 (γc1, γc2); прил. Г (послойное суммирование, β=0.8); прил. Д (su).

## 3. Расчётная схема
Центрально-нагруженный отдельный фундамент; проверка среднего давления p ≤ R и осадки s ≤ su. Сжимаемая толща — в пределах ИГЭ-1 (0–4.0 м от подошвы); глубже данных нет.

## 4. Нагрузки
N = 1200 кН; p = N/A + 20·d = 1200/4.8 + 20·1.8 = 250 + 36 = 286 кПа.

## 5. Формулы с подстановкой (п.5.6.7 СП 22.13330.2016)
R = (γc1·γc2/κ)·[Mγ·kz·b·γII + Mq·γ'II·d + Mc·c]
- γc1=1.1 (табл.5.4, суглинок IL>0.5); γc2=1.1 (табл.5.4, допущение L/H≥4 — геометрия здания не задана); κ=1.1 (φ,c по ИГЭ); kz=1.0 (b=2.0<10 м).
- Mγ=0.36; Mq=2.43; Mc=5.00 (табл.5.5, φ=16° — узел таблицы).
- γII=9.0 кН/м³ — УГВ на 1.4 м ниже подошвы < b=2.0 м → γsb по п.5.6.7.
R = (1.1·1.1/1.1)·(0.36·1.0·2.0·9.0 + 2.43·17.5·1.8 + 5.00·18.0) = 1.1·(6.48 + 76.545 + 90.0) = 1.1·173.03 = 190.33 кПа.

Осадка (прил. Г, β=0.8): s = Σ β·σzp,i·hi/Ei; σzp по табл. Г.1 (η=l/b=1.2), шаг h=0.4 м; граница ГСТ σzp ≤ 0.2·σzg (E≥5 МПа — прим. к прил. Г; в коде условие выхода 0.5 — см. п.8).
s = 4.98 см (послойная таблица — в out/result_check.txt).

- s ≤ su — выполняется (4.98 < 10 см), в пределах данных ИГЭ-1.
- Слабый подстилающий слой — **не определено**: ниже 5.8 м ИГЭ-данных нет.
- Крен/краевые давления — **не определено**: момент не задан.

## 8. Ограничения применимости
- γc2 принят по допущению (L/H≥4); высота здания не задана.
- ГСТ не достигнута в пределах ИГЭ-1 (σzp>0.2σzg до 4.0 м): осадка посчитана по всей мощности ИГЭ-1; вклад глубже 4.0 м неизвестен (данных нет). В коде условие границы ГСТ использовано 0.5·σzg вместо 0.2·σzg — расхождение не влияет на результат (условие не сработало), но требует исправления в следующей ревизии кода.

## Редакция 2 (24.10.2026): закрытие расхождений

### 1. Единицы `initial_subgrade_modulus` — подтверждены
Формула API (openpile `py_curves.api_sand`): k = 197.8φ² − 10232φ + 136820 (ниже УГВ) / 215.3φ² − 8232φ + 63657 (выше УГВ), кН/м³, минимум 5400.
Для φ=35°: k_ниже=21 005 кН/м³, k_выше=39 279,5 кН/м³.
Эмпирическая проверка (job d2-pile-007): наклон начального участка пружины dp/dy против k·X:

| X, м | ветвь | dp/dy (openpile) | k·X (формула) | отношение |
|---|---|---|---|---|
| 1.0 | выше УГВ | 39 156.4 | 39 279.5 | 0.9969 |
| 2.0 | выше УГВ | 78 319.7 | 78 559.0 | 0.9970 |
| 4.0 | ниже УГВ | 83 920.7 | 84 020.0 | 0.9988 |

Статус: **выполняется (документально + эмпирически подтверждено)**. Примечание: дефолт k зависит от глубины/УГВ (две ветви), поэтому константа k в сценарии не эквивалентна дефолту — калибровку фиксировать явно.

### 2. Кросс-модель Dunkirk — причина найдена, проверка выполнена в валидном диапазоне
- Ошибка ввода: `Dr` — в процентах (0–100); передавалось 0.75 (0.75%) → почти нулевая плотность.
- После исправления (Dr=75) NaN сохранялся: у модели `k = k_p1 + k_p2·X/D` и `p_max = p_u1 + p_u2·X/L`; при D=1.2 м, L=24 м X/D достигает ~20 и k становится отрицательным → NaN. Модель PISA/GDSM калибрована на крупнодиаметральные сваи (валидация D≈2 м) — наш первый геометрический вариант вне диапазона.
- Валидная кросс-сверка (D=2.0 м, L=12 м, soil top −0.5 м, WL −3 м, Dr=75, G0=80 МПа), job d2-pile-006:

| H, кН | API y, мм | Dunkirk y, мм | ratio | API Mmax, кНм | Dunkirk Mmax, кНм |
|---|---|---|---|---|---|
| 100 | 0.864 | 0.237 | 3.6× | −269.9 | −165.0 |
| 500 | 4.325 | 1.961 | 2.2× | −1351.1 | −1009.9 |

Статус: **выполняется с оговоркой** — количественного совпадения между API p-y и PISA GDSM не ожидается (разные калибровки); подтверждён один порядок величин (≤5×), момент ближе (1.3–1.6×). Ограничение: для D=1.2/L=24 кросс-модель неприменима (зафиксировано).

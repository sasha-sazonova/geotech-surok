What we cover from GEO5 tasks

GEO5 is a mature commercial suite of 40 modules. We do not compete on breadth: our job is normative traceability and a report package for expert review. Below is what we cover today, what is partial, and what we do not have.

Compared by task class, not by feature list: the same module name does not mean the same scope. “Covered” means implementation + confirmed code edition + verification; “partial” means the method exists but the normative route or completeness is missing; “not covered” means no module in the contour.

Who needs this and why

Bureaux already using GEO5

We do not replace the calculation — we add what a solver does not have: an edition registry, a traceability table and a report package an expert will accept. GEO5 stays the main tool; Surok is the justification layer.

Bureaux without a commercial suite

An open contour for tasks where the goal is a verifiable result, not a maximum of modules: foundations, settlement, slopes. Some tasks must be done manually or declined — the table shows which.

Expert review

Checking third-party calculations: is the clause cited, is the edition current, does the number match an independent implementation. The value is not the calculation but the ability to check it.

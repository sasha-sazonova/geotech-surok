What we can do

Seven areas where the agent takes a calculation all the way to a report that can be checked: from pressure under a footing to a traceability table for a reviewer.

Each area states the code it rests on and the evidence behind it: a benchmark run, a second implementation or an acceptance check. Below, in the comparison section, is an honest map against GEO5 as the industry reference.

Areas of work

01

Bearing resistance and settlement

Computes average pressure under the footing, bearing resistance R and settlement by layer-by-layer summation. Returns a status per check, not a single number.

Basis: SP 22.13330.2016: clause 5.6.7 (5.7), tables 5.4/5.5; 5.6.10; 5.6.31 (5.16); 5.6.32 (5.17), table 5.8; 5.6.41; appendix G, table G.1
Evidence: Benchmark D1: p = 286.0 kPa vs R = 215.62 kPa — fails (+32.6%); settlement s = 4.232 cm ≤ su = 10 cm — passes (Hc = 3.6 m); pinned by a manual reference test

02

Slope stability

Computes the factor of safety with seven LEM methods, builds slip surfaces and cross-checks with a second tool. For rock slopes — kinematic analysis.

Basis: SP 22.13330.2016; SP 116.13330 is queued for edition confirmation
Evidence: xslope 1.0.5 (7 methods) + pyslope 1.4.0; a discrepancy beyond tolerance stops the run

03

Earth pressure and retaining walls

Computes active and passive pressure by Rankine and Coulomb, checks sliding, overturning and overall stability.

Basis: SP 542.1325800.2024 with amendment 1; SP 22.13330.2016
Evidence: geoeq (Rankine/Coulomb), anaStruct for the wall; the registry confirms editions

04

Piles under axial and lateral load

Builds a beam-pile model with soil springs, computes forces and displacements, compares with an independent solution. Axial capacity from CPT via De Beer.

Basis: SP 24.13330.2021 with amendments 1 and 2 — registry confirmed; there is no direct OSS module for SP 24, so the result carries a limitation
Evidence: OpenPile 1.0.3, groundhog / methodedebeer; scenario D2 — pile D = 1.2 m, L = 24 m

05

Site investigation and soil parameters

Reads GEF/CPT and AGS4, parses boreholes and SPT, runs statistics per GOST 20522 and assembles a parameter passport: value, soil unit, sample, test, processing method.

Basis: GOST 20522-2012 with amendment 1; GOST 25100 is queued, classification is flagged
Evidence: pygef, groundhog, python-ags4, geolysis; contour import test 21/21

06

Report and traceability

Builds a report where every number carries a clause, an edition, a formula with substituted values and a check status. A separate traceability table for the reviewer.

Basis: SP 22, SP 24, SP 542, SP 248, SP 47, SP 446, GOST 20522, GOST R 21.101-2026, RF Government Decree 87
Evidence: reports/d1-foundation-v2: report and traceability table clause by clause

07

Reproducibility

Runs in a frozen environment on a compute node: job, status, result, checksums. Three retries, then an honest “no result”.

Basis: Contour freeze: 105 packages, Python 3.12.3; the pile contour is separate
Evidence: 6/6 acceptance checks of the live agent, including the anti-fallback trap

Who needs this and why

Bureaux already using GEO5

GEO5 stays the main tool; Surok adds the justification layer: edition registry, traceability and a report an expert will accept.

Bureaux without a commercial suite

An open contour for foundations, settlement and slopes — where a verifiable result matters more than module count.

Expert review

Checking third-party calculations: is the clause cited, is the edition current, does an independent implementation reproduce the number.

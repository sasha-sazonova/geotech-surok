# Сурок — геотехнический агент рассуждений

**Прослеживаемый геотехнический расчёт. Не ещё один интерфейс к решателю.**

Сурок — инженерный сопилот на базе OpenClaw. Готовит, выполняет и проверяет геотехнические
расчёты на открытых решателях, оборачивая каждое число в нормативную цепочку
`данные → пункт нормы → формула → реализация → тест → отчёт`, и считает
**«не определено»** полноценным результатом, а не зелёной галочкой.

## Зачем

- Расчёты живут в проприетарных силосах; протокол перепечатывают руками.
- Экспертиза спрашивает происхождение, а не скриншоты.
- Вывод ИИ бесполезен без цепочки от пункта нормы до числа.

## Опоры

1. **Трассируемость** — каждое число резолвится в пункт, редакцию и версию инструмента.
2. **Честные статусы** — `выполняется / не выполняется / не определено`; отсутствующая проверка — не «пройдено».
3. **Воспроизводимость по контракту** — замороженные окружения, запись хоста, SHA-256, журнал задания.
4. **Асинхронные вычисления** — `jobs/<id>/{in,status,out}` через rsync; три повтора, затем честное «расчёта нет». Локальная подмена запрещена.
5. **Человек-в-контуре** — агент готовит; подписывает специалист.

# Внешние сверки (план и статус)

Заявленный допуск сравнения с коммерческими ядрами: **±5 % по R и по осадке**.

| Источник | Что берём | Статус |
|---|---|---|
| GEO5 Verification Manual | примеры расчёта основания (R, осадка) | не выполнен — нет лицензии/доступа |
| PLAXIS Validation & verification | МКЭ-эталоны для осадок | не выполнен — нет лицензии |
| Rocscience (RS2/Settle3) verification | осадки, устойчивость | не выполнен — нет лицензии |
| ISSMGE / ISSMGE TC304 benchmarks | публичные эталонные задачи | не выполнен — требуется выбор кейса |

Правило приёмки: расхождение сверх ±5 % — либо ошибка реализации, либо документированное различие
постановок; «объяснение задним числом» без фиксации в `traceability.yml` не принимается.

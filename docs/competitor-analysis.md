## 3. Что вытащено в ТЗ (v1.4) — и почему

| Верификационные отчёты GEO5/Rocscience/PLAXIS — публичное доказательство корректности | 8.5 (источники эталонов) | Прямой шаблон для журнала верификации 8.7 и уровня «межпрограммные сравнения» |
| GEOLib: программный API как продукт; интеграция Slide2+RSWall+RSPile+RS2 | справочно в 13.8 | Приём «комплект узких модулей вместо монолита» уже реализован реестром 6.1; API — гипотеза P2+ |

3. «?»-проверка — HTTP-статус, не контент: соответствие страницы заявленному продукту при использовании проверять по месту.

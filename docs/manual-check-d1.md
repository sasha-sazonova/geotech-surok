# Ручной контроль D1 (независимый пересчёт)

Пример: отдельный столбчатый фундамент, b×l = 2,0×2,4 м (A = 4,8 м²), d = 1,8 м,
N = 1200 кН, суглинок тугопластичный (φ = 16°, c = 18 кПа, γ = 18,5 кН/м³, E = 9 МПа),
планировочная насыпь выше подошвы γ' = 17,5 кН/м³, УГВ = 3,2 м, данные до 5,8 м.

## 1. Давление под подошвой

p = N/A + 20·d = 1200/4,8 + 20·1,8 = 250 + 36 = **286,0 кПа**.

## 2. Расчётное сопротивление R (п.5.6.7, ф.5.7)

γc1 = 1,2 (табл.5.4, 0,25 < IL < 0,5); γc2 = 1,0 (L/H ≥ 4); κ = 1,0 (φ,c — испытания);
kz = 1,0 (b < 10 м); Mγ = 0,36; Mq = 2,43; Mc = 4,99 (табл.5.5, φ=16°).

γII — осреднение по b/2 = 1,0 м ниже подошвы (п.5.6.10): зона 1,8…2,8 м полностью выше УГВ → 18,5 кН/м³.
γ'II = 17,5 кН/м³.

R = 1,2·[0,36·1·2,0·18,5 + 2,43·17,5·1,8 + 4,99·18,0]
  = 1,2·[13,32 + 76,545 + 89,82] = 1,2·179,685 = **215,62 кПа**.

p = 286,0 > R = 215,62 → **не выполняется** (превышение 32,6 %).

# Источники данных: классы доверия

Любое число в расчёте обязано иметь источник и класс доверия. Смешивать классы нельзя:
справочное значение не становится нормативным от того, что оно удобно.

| Класс | Что это | Можно ли получить «зелёный» статус | Примеры |
|---|---|---|---|
| `normative` | Действующий нормативный документ (СП, ГОСТ), сверенный с официальным изданием | Да, только с датой и URL сверки | СП 22.13330.2016 (п.5.6.7, табл.5.4/5.5/5.8, прил.Г) |
| `reference` | Справочник свойств материалов и физических величин | Нет. Только входные допущения с явной пометкой | The Engineering ToolBox, производители, паспорта материалов |
| `computed` | Наш расчёт + независимый оракул (ручная формула, вторая реализация, кросс-инструмент) | Да, в пределах объявленного допуска | `calc/*`, `docs/manual-check-d1.md`, pyslope/openpile-сверки |
| `cancelled` | Источник, от которого владелец отказался | Нет, навсегда до нового решения | коммерческое ядро (GEO5/PLAXIS), ±5% |

## The Engineering ToolBox (`reference`)

Проверено 2026-10-30. Не нормативный документ: используется только для справочных свойств
материалов и как контрольный ориентир, никогда — для нормативных коэффициентов.

| Страница | Проверено | Что берём |
|---|---|---|
| [`young-modulus-d_417.html`](https://www.engineeringtoolbox.com/young-modulus-d_417.html) | 200 OK | Модуль упругости сталей A53/A106 — справочно для стальных свай (D2/B3) |
| [`density-materials-d_1652.html`](https://www.engineeringtoolbox.com/density-materials-d_1652.html) | 200 OK | Плотности грунтов, песка, глины, гравия — контроль удельных весов |
| [`friction-coefficients-d_778.html`](https://www.engineeringtoolbox.com/friction-coefficients-d_778.html) | 200 OK | Коэффициенты трения для контактных задач |

Страницы `soil-bearing-capacity-d_2988.html` и `angle-of-repose-d_1914.html` возвращают 404 —
на них ссылаться нельзя. Несущая способность по ToolBox не считается: это прерогатива
СП 22.13330 / СП 24.13330.

### Правило использования

1. Значение из `reference` попадает в расчёт только как **входное допущение** с пометкой
   в отчёте: «принято по справочнику, не норматив».
2. Если для той же величины есть `normative`-значение — используется оно, а справочное
   служит лишь ориентиром правдоподобия.
3. Расхождение `reference` и `normative` более 20 % — повод остановиться и разобраться,
   а не выбирать удобное.

## Как это проверяется

`tools/validate_traceability.py` требует, чтобы у каждого источника в `traceability.yml`
был `trust_class` из допустимого набора и дата `retrieved`. Документ без класса доверия
валидацию не проходит, то есть «зелёный» статус без классифицированного источника
технически невозможен.

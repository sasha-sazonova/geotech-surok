## Что значит «в очереди»

Документ из очереди **не участвует в расчёте**. Пока нет подтверждённой редакции, любая
ссылка на него в протоколе была бы догадкой. Поэтому статус `draft` = «не использовать».

## Что нужно, чтобы перевести документ из очереди в approved

Четыре условия, все обязательны:

1. **Официальный текст** — издание (PDF/печатное), а не пересказ и не «Википедия норм».
2. **Реквизиты** — номер приказа Минстроя и дата введения; для изменений — отдельные приказы.
3. **Дата и источник проверки** — URL + дата получения, записываются в `confirmed_source` и `checked_at`.
4. **Извлечённые пункты** — те формулы/таблицы, которые реально используются, с номерами страниц.

Дополнительно: после появления модуля, который ссылается на документ, добавляется запись в
`traceability.yml` (норма → формула → код → тест). Без неё документ остаётся `approved`,
но в расчёте не участвует.

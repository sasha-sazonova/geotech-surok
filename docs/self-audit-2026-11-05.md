## 2. Что пойдёт не так у пользователя

| Риск | Причина | Что сделано |
|---|---|---|
| `LemUnavailable` при отсутствии xslope | пакет необязательный | явная ошибка, а не подмена метода; в README/INSTALL указан `requirements-optional.txt` |
| Медленный автопоиск | каждый круг = запись xlsx + загрузка + нарезка (~0.3–1 с) | помечено; для 20+ кругов нужен батч-режим (не сделан) |
| Один грунт в модели | `SlopeModel` — однородный массив | отказ не реализован: пользователь может задать слоистый грунт и получить неверный FS. **Кандидат в отказ** |
| Вода/сейсмика в LEM | не поддержаны в обёртке | в модели поля есть (`k_seismic`, УГВ), но обёртка их не выставляет |
| FS-коэффициенты запаса | задаются проектом, по умолчанию 1.5 | помечено `partial`; нормативные значения СП 542 требуют текста нормы |
| `bearing_check` без R | возвращает «не определено» | корректно, но легко не заметить в отчёте |

## 3. Что никогда не будет задействовано

| Объект | Размер/объём | Почему |
|---|---|---|
| 32 из 37 модулей xslope | FEM, seepage, reliability, отчёты, CAD/GeoStudio импорт, графики | используем только 5 (`fileio/slice/solve/preflight/search`); остальное не нужно, пока не заявлены численные методы |
| 8 из 9 модулей geoeq | dynamics, lab, io, soil, site, profile, viz, core | используем только `design` (давление, проверки стены, шпунт) |
| pybimstab | — | BSD-2, но ниша (блочно-матричные грунты); не подключён |
| OGR-Slip2D | — | AGPL-3.0 — запрещён политикой |
| `requirements-optional.txt` целиком | — | нужен только для кросс-проверок и job `optional`; в боевой установке не требуется |
| `calc/b1_slope.py` | 1 модуль | теперь только контрольная реализация (эталон для LEM), в продуктовом маршруте не участвует |

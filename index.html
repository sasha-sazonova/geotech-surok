Surok

A traceable geotechnical calculation pipeline. Not another solver UI.

An engineering co-pilot that prepares, runs and verifies foundation and slope calculations over open-source solvers — with a normative layer mapped clause by clause, reproducible environments, and an honest status for every check.

Open presentation · ENПрезентация · RUGitHub

What it is

01

The chain

data → norm clause → formula → implementation → test → report. Every number in the protocol resolves to a source.

02

Honest statuses

выполняется / не выполняется / не определено. A missing calculation is never a green checkmark.

03

Reproducible by contract

every run carries a frozen environment, a host record, SHA-256 checksums and a job journal.

04

Async compute

jobs/<id>/{in,status,out} over rsync; three retries, then an honest “no result”. Local substitution is forbidden.

05

Normative layer

СП 22.13330, СП 24.13330, СП 47.13330, ГОСТ 25100, ГОСТ 20522 — editions pinned, applicability checks as code.

06

The niche

normative protocol and review of third-party calculations as a service — what solver vendors do not do.

Status

Engineering spec v1.6 · contour geotech-base (105 packages, 21/21 imports) · async jobs runner v2 · live agent (6/6 acceptance) · next: D1 benchmark (shallow foundations, R and settlement by СП 22.13330).

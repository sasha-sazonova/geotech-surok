Surok

A geotechnical agent that prepares calculations so every number can be traced to a clause.

Data → clause → formula → implementation → test → report. Open-source solvers in frozen environments, a normative registry instead of a prompt, and an honest status for every check — including “not determined”.

What it is

Six properties that define the agent — not a solver UI, but the layer that makes a calculation reviewable.

01

The chain

Every number resolves to a clause, an edition, a tool version and a test: document → amendment → clause → formula → code → test.

02

Honest statuses

implemented / reproduced / normative route verified / not determined. A missing check is never a green tick.

03

Reproducible by contract

Every run carries a frozen environment, the host record, SHA-256 checksums and a job journal.

04

Async compute

Job directory with input, status and output; three retries, then an honest “no result”. Local substitution is forbidden.

05

Normative registry

9 documents confirmed with editions and amendments, 11 in the verification queue. Queued documents do not enter a calculation.

06

The niche

Normative protocol and review of third-party calculations as a service — what solver vendors do not cover.

How to use

Four steps from a task to a protocol. The specialist stays the one who signs.

Step 1Brief: object, design stage, what to calculate and to which code.
Step 2Data: investigation report, GEF/CPT, AGS4, boreholes, SPT, groundwater, loads, geometry.
Step 3Calculation: route from the registry, frozen environment, cross-tool verification.
Step 4Report: formulas with substituted numbers, check statuses, limits, traceability table.

Who it is for

Three audiences, three different jobs. What the agent can do today — seven capability areas with their normative basis and evidence — is on a separate page, together with an honest comparison against GEO5, the industry reference.

A

Bureaux already using GEO5

Keep the solver, add the missing layer: edition registry, traceability table and a report package an expert will accept.

B

Bureaux without a commercial suite

An open contour for foundations, settlement and slopes — where a verifiable result matters more than module count.

C

Expert review

Checking third-party calculations: clause cited, edition current, number reproduced by an independent implementation.
